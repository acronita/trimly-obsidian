Everything in the Trimly project (Obsidian personal-finance plugin) is in English: UI texts, notices, modals, README, docs, comments, commits. Conversation with the user stays in Portuguese. Same rule as the user's Maguilanote plugin.

**Why:** plugin may be published publicly; English is the standard for Obsidian community plugins.

**How to apply:** write every string and doc in English.
